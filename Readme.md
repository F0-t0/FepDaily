<h1 align="center">FepDaily</h1>

## Instalacja:
1. Pobierz plik FepDaily.jar
2.  Wrzuć go do folderu plugins na twoim serwerze
3. Wystartuj serwer
4. Wrzuć do configu token twojego bota i channelid
5. Zrestartuj serwer
